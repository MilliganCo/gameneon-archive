# GameNeon

## О проекте

`GameNeon` — компактная браузерная мини-игра в неоновом стиле. Вся логика сосредоточена в трёх файлах, поэтому проект удобен как быстрый игровой прототип и как учебный пример простой web-игры без сборщиков и фреймворков.

## Состав проекта

- `index.html` — структура страницы и игрового контейнера;
- `style.css` — визуальный стиль и неоновое оформление;
- `game.js` — состояние игры, классы персонажа, враги, магазин, апгрейды и базовая игровая логика.

## Особенности

- несколько игровых классов с разными параметрами и навыками;
- здоровье, энергия, опыт, кредиты и инвентарь;
- враги, боссы, магазины и система улучшений;
- запуск без дополнительной сборки.

## Запуск

Откройте `index.html` в браузере.

## Статус

Готовый мини-прототип. Проект небольшой по объёму, но уже содержит самостоятельный игровой цикл и набор RPG-like систем.
